Pairing guide
  1. Install and enable the Codex extension from the GitHub repository.
  2. In Codex, call start_pairing from Codex Thunderbird.
  3. Paste the bridge URL and six-digit PIN here, then click Pair.
  4. Use Manage allowed accounts to decide which Thunderbird accounts Codex may access.
